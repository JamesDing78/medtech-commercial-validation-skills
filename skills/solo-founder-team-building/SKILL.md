# Solo Founder Team Building

## Workflow
1. Design the first 90 days around what one owner can actually do.
2. Classify all work into owner-led, manufacturer-supported, outsourced expert, delayed, or first-hire.
3. Define first hires only when there is a trigger: pipeline volume, installations, service tickets, regulatory workload, or recurring revenue.
4. Put headcount, contractor fees, travel, commission, and service load into the financial model.

## Default Team Path
0-3 months: solo owner plus project-based experts and manufacturer support.
3-12 months: BD and application engineer.
12-36 months: regional sales, application, customer success/service, data/report analyst, marketing/academic operations, and channel manager.

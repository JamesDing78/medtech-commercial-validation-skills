# Global Medtech Regulatory Classification

## Workflow
1. Define intended use, indications, users, patient population, output report, and decision impact.
2. Search FDA product classification/510(k)/PMA, NMPA classification catalog/classification decisions, and EU MDR Annex VIII/Rule 11.
3. Map non-medical, Class I, Class II/IIa, Class IIb, and Class III possibilities.
4. Produce pathway, standards, evidence needs, timeline, cost assumption, and unresolved classification questions.

## Guardrails
- Never assert final classification without confirmed labeling and intended use.
- Treat AI treatment recommendation, diagnosis, and closed-loop control as higher-risk paths.

# After-Sales Service System

## Workflow
1. Segment service objects by installation complexity and clinical/teaching criticality.
2. Define warranty, annual maintenance, premium SLA, training, calibration, spare parts, and data service packages.
3. Build ticket taxonomy: hardware, software, calibration, protocol, data quality, user training, integration, complaint, adverse event.
4. Model service capacity: response time, engineer load, spare-part cost, travel, vendor dispatch, warranty reserve, renewal rate.
5. Feed repeated issues into product improvement, training content, and sales objections.

## Solo-Founder Guardrail
When the project owner is alone, do not promise SLA that depends on unavailable engineers or manufacturer resources.

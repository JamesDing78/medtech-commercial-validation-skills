# Sim-to-Real Feasibility

## Workflow
1. Identify the controlled setting and the real-world target setting.
2. Compare constraints: lighting, space, calibration, user skill, patient/student cooperation, device setup time, data quality, safety, and privacy.
3. Define acceptance metrics: setup time, repeatability, missing data rate, report turnaround, accuracy proxy, and service cost.
4. List what must be standardized before scale: protocols, templates, training, troubleshooting, and record/replay review.

## Decision Rule
Call a setting feasible only when the operating burden, service burden, and data quality are compatible with the buyer's workflow and budget.

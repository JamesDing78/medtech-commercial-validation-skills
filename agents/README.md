# Agent 角色绑定示例

这些片段只用于说明如何绑定 Skill，不是可直接覆盖的个人配置文件。

## CEO

```text
涉及医疗科技、康复、运动健康、教育健康、To C 或具身智能产品线商业验证时，先使用
$customer-evidence-medtech-commercial-validation 完成客户证据、客户 ROI 和继续/暂停闸门，
再派发实现与审查任务。
```

## 码农

```text
涉及医疗科技产品线商业模型、客户 ROI、医保/合规、风险闸门或互动交付时，先读取并遵循
$customer-evidence-medtech-commercial-validation；保持事实、假设、目标和历史口径分离。
```

## 审核员

```text
审查医疗科技产品线方案、财务模型、销售路径或路演交付时，使用
$customer-evidence-medtech-commercial-validation 检查客户证据、ROI、合规红线、风险闸门、
模型口径、来源日期和空值状态。
```
